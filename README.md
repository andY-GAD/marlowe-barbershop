# Marlowe Barbershop

A responsive one-page website for a fictional Nairobi barbershop.

## Live demo
https://andY-GAD.github.io/marlowe-barbershop

## Tech used
- HTML5, CSS3, vanilla JavaScript
- No frameworks — built from scratch

## Features
- Fully responsive layout (mobile-first breakpoints)
- Scroll-triggered reveal animations via IntersectionObserver
- Styled booking form with validation
- CSS custom properties (variables) for easy theming

## What I'd add next
- Real backend (PHP + MySQL) to actually store bookings
- Image gallery with real photos
